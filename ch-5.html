Programming Concepts

5.1 Programming Concept

A computer needs instructions to follow because it cannot think on its own. For instance, when playing a game of solitaire you must choose which card to move. Each time a card is moved, a set of instructions has been executed to carry out the move. These instructions compose only a small part of the solitaire program. This program comprises many more instructions that allow a user to perform actions, such as beginning or ending a game, selecting a card's color, and so forth. Therefore, a computer program comprises instructions that direct the actions of the computer. In essence, a a program plays the role of guide for a computer. It tells the computer what steps in what order should be taken to complete a certain task successfully.

5.1.1 Introduction to Programming Languages

A computer program is a sequence of instructions written in a programming language to perform a specific task. It is also referred to as software and can consist of just a few lines or millions of lines of code. These instructions, known as the source code, guide the computer's operations. The act of writing these instructions is known as programming or coding. Without programs, a computer is merely a non-functional machine - programs give it functionality and purpose.

Programmers use different types of programming languages depending on the task at hand and their own knowledge and experience. Each language has its own set of characters and syntax rules, much like how natural languages have grammar. Following these rules correctly is essential in writing functional and error-free programs.
